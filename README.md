# AI-платформа для обработки карточек товаров (кейс М.Видео)

Веб-платформа на Django для извлечения и нормализации характеристик товаров из текста карточки (заголовок, описание, атрибуты продавца). Для каждого значения хранятся нормализованный вид, уверенность, способ извлечения и статус проверки. Сомнительные значения попадают на ручную проверку.

## Статус проекта

| Часть | Состояние |
| --- | --- |
| Справочники (категории, атрибуты, допустимые значения, синонимы) | готово |
| EDA: загрузка CSV/JSON, пропуски, типы, распределения, качество по категориям | готово |
| Результаты: очередь проверки, фильтры, ручное исправление, подсветка значения в тексте | готово, на демонстрационных данных |
| Настройки: пороги уверенности и параметры LLM | готово |
| Модуль извлечения (Regex + LLM), обработка карточки и CSV, оценка качества | в разработке, пока не подключён |

Метрики качества в репозитории не приводятся, потому что они считаются только по реальному размеченному датасету. Демонстрационные данные на странице «Результаты» не являются результатом работы алгоритма.

## Требования

- Python 3.11 или новее
- Доступ в интернет для установки пакетов и загрузки Tailwind, шрифтов и Chart.js с CDN

## Установка и запуск

```bash
git clone https://github.com/MagomedAbdulaev/mvideo.git
cd mvideo

python -m venv venv
# Windows (cmd):        venv\Scripts\activate
# Windows (PowerShell): venv\Scripts\Activate.ps1
# Linux / macOS:        source venv/bin/activate

pip install -r requirements.txt

# переменные окружения (необязательно для локального запуска)
# Windows: copy .env.example .env     Linux/macOS: cp .env.example .env

python manage.py migrate
python manage.py seed_demo      # демо-данные для страницы «Результаты» (необязательно)
python manage.py runserver
```

Сайт откроется на http://127.0.0.1:8000/.

### Запуск на сервере (порт 8000)

```bash
python manage.py runserver 0.0.0.0:8000
```

Публичный адрес сервера нужно добавить в `.env`, иначе Django откажет в доступе:

```
DJANGO_ALLOWED_HOSTS=localhost,127.0.0.1,адрес-сервера
```

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/` | Главная: сводка (пока демонстрационные цифры) |
| `/review/` | Результаты: проверка сомнительных, конфликтующих и неизвестных значений, ручное исправление |
| `/eda/` | Разведочный анализ данных: загрузка датасета и расчёт статистики |
| `/dictionaries/` | Справочники атрибутов и допустимых значений |
| `/settings/` | Пороги уверенности и параметры LLM |
| `/process/`, `/evaluation/` | Заглушки, будут добавлены вместе с модулем извлечения |

### Как проверить EDA на своих данных

1. Откройте `/eda/`.
2. Загрузите CSV или JSON с карточками товаров (кодировка UTF-8 или Windows-1251, разделитель CSV определяется автоматически).
3. Страница покажет размер данных, дубликаты, заполненность, пропуски и распределения по каждому полю, а также размер категорий и долю пропусков в них. Все значения считаются по загруженному файлу.

Датасет сохраняется в `data/`, эта папка не входит в репозиторий.

## Настройки

Переменные окружения (файл `.env`, образец в `.env.example`):

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `DJANGO_SECRET_KEY` | секретный ключ Django | небезопасный ключ для разработки |
| `DJANGO_DEBUG` | режим отладки | `True` |
| `DJANGO_ALLOWED_HOSTS` | разрешённые хосты через запятую | `localhost,127.0.0.1` |
| `OLLAMA_BASE_URL`, `OLLAMA_API_KEY`, `OLLAMA_MODEL` | параметры LLM | см. `core/settings.py` |
| `CONFIDENCE_HIGH`, `CONFIDENCE_LOW` | пороги уверенности | `0.85`, `0.60` |

Пороги и параметры LLM можно менять на странице `/settings/`, изменения сохраняются в `data/settings.json`. Ключи в репозиторий не попадают.

## Подход к извлечению

1. Regex закрывает очевидные значения: бренд, объём памяти, диагональ, ёмкость батареи.
2. LLM обрабатывает только то, что не закрыли правила, чтобы не платить за вызов на каждую карточку.
3. Нормализация по справочнику: «алый», «red» и «красный» приводятся к одному значению.
4. Проверка типа, допустимых значений и того, что значение есть в тексте карточки.
5. По порогам уверенности значение принимается, уходит на проверку или помечается неизвестным.

Ручные исправления сохраняются вместе с исходным ответом алгоритма (`auto_value`), чтобы возвращать их в правила и справочники.
